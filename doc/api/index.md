# API reference

The C++ API is generated by Doxygen from the headers under `projects/*/src`.

- **Curated pages** (this section) present the classes a user or new developer meets first,
  module by module, with their members.
- The **<a href="../doxygen/index.html">full Doxygen index</a>** covers every class, file, and namespace
  — about 700 classes. Use its search box to find a symbol.

Much of the code base is not yet documented with Doxygen comments, so many members appear with
their signature only. Adding comments is the most direct way to improve these pages; see
{doc}`../developer/documentation`.
