# Example map

Every example deck in `projects/EXA`, linked to the examples it most resembles. Two examples are
connected when their decks share detected features — the physics (from the IWG types), the
optimizer, the geometry representation, ghost stabilization and Nitsche enforcement, the heat
method, adaptive refinement, the spatial dimension — and an edge is wider the more they share.
Everything is derived from the deck sources at build time, like the {doc}`catalog <catalog>`.

Drag to pan, scroll to zoom, hover a node for its features, click it to open the example's page.
The menu highlights every example with one feature. Each example page carries the same graph
reduced to its own nearest neighbours.
